# Module 006 — Founder-led Sales v0

> **Stage:** SEED · **Pillar:** GTM / Sales · **Prereq:** mod-002

**Status:** stub — objectives and target artifact defined; lesson filled by the
autonomous pipeline.

## Objectives

1. Run the founder-led sales motion when **nobody knows who you are**: discovery →
   qualification → pilot → contract.
2. Qualify hard (who is *not* a fit) and design a pilot that proves value.
3. Learn what you can only learn by selling it yourself before you hire sales.

## Founder artifact — the exercise

> Write the **founder-led sales script** for one real prospect: the discovery call
> questions, your qualification criteria, the pilot you'd propose (scope, success
> metric, duration), and the path from a successful pilot to an enterprise
> contract. Note what a "no" at each stage teaches you.

Deliverable: the script + qualification criteria + pilot design.

> Depends on mod-002: you sell the value proposition you modeled, to the segment
> you defined.
