# Module 004 — Fundraising: Pre-seed → Seed

> **Stage:** PRE-SEED→SEED · **Pillar:** Fundraising · **Prereq:** mod-003

**Status:** stub — objectives and target artifact defined; lesson filled by the
autonomous pipeline.

## Objectives

1. Understand the ladder: **angels → pre-seed → seed → Series A** — who invests,
   check sizes, what each expects.
2. Run fundraising as a **pipeline**: sourcing, conversion, momentum, close.
3. Know what a raise is *for* (from mod-003's model) and how much to raise.

## Founder artifact — the exercise

> Create an **investor funnel from 200 targets**: segment them, set conversion
> assumptions at each stage (target → first meeting → partner meeting → term sheet),
> and compute how many term sheets the funnel implies. State the assumptions you'd
> most want to be wrong about.

Deliverable: the funnel (table) + conversion assumptions + implied outcomes.

> Depends on mod-003: you raise against a model, not a vibe.
