> **How do I go from idea → company → functioning organization, and allocate
> capital, attention, people, and strategic direction along the way?**

The Founder/CEO path through the [`ai-startup-curriculum`](https://github.com/ai-startup-curriculum)
— a role *pathway* over the shared functional curricula, not a separate body of
knowledge. Start with **[startup-foundations](https://github.com/ai-startup-curriculum/startup-foundations)**,
then work the modules your stage calls for.

This curriculum is built as a **live laboratory**: it's written roughly one level
above where a real, currently-operating startup is at each moment, turning the
chaotic education a technical founder actually gets — incorporation, fundraising,
partnerships, runway, board dynamics — into a systematic path the next founder
doesn't have to discover the painful way.

## Learn by building founder artifacts

Every module ends in a real deliverable, not a quiz: a customer-discovery synthesis,
a lean canvas, an 18-month runway model, an investor funnel, a cap table with a
SAFE and an option pool, a founder-led sales script. Worked exemplars live under
[`exemplars/`](./exemplars) — reference deliverables, not code solutions (this is
a single-repo curriculum; there is no separate solutions repo).

## Layout

```
├── exemplars/mod-XXX-*/   worked reference deliverables for the exercises
├── projects/             multi-module founder capstones
├── CURRICULUM.md         the module spine (stage-tagged, dependency-linked)
└── README.md             this file
```

## Where to start

Read [CURRICULUM.md](./CURRICULUM.md), find your **stage**
(`IDEA → PRE-SEED → SEED → SERIES-A → GROWTH → MATURE`), and start at the earliest
module tagged for it. Pre-seed? Begin with **mod-001 Customer Discovery**.
