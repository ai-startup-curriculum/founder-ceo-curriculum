# Exemplar — Module 001 Customer Discovery Sprint

A worked reference for [exercise-01-discovery-sprint](../../lessons/mod-001-customer-discovery/exercise-01-discovery-sprint).
It applies the method to the simulated scenario (a staged startup curriculum for
technical founders) so you can see what "strong" looks like end to end.

This is a **reference deliverable, not an answer key** — your segment, questions,
and conclusion will differ. Compare *method and rigor*, not wording.

Contents:

- **[discovery-plan.md](./discovery-plan.md)** — segment definition, recruit
  strategy, and a Mom-Test-clean interview guide (artifact #1).
- **[insight-memo.md](./insight-memo.md)** — synthesis across interviews with a
  defended go / pivot / kill call and named disconfirming evidence (artifact #2).
